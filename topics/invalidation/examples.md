# Invalidation Examples

## Default Structural Stop

- Confirm the protected swing first.
- Put bullish invalidation below the protected low.
- Put bearish invalidation above the protected high.

## Body-Based Risk Tightening

- Start from the full protected-swing invalidation.
- Only tighten to the candle body when the swing is supported by bulk opposing candles rather than big wicks.
- Treat the tighter stop as a risk-reward variant, not as stronger structure.

## Wait For Better Structure

- If the initial reversal stop is too wide for the available target, skip the entry.
- Wait for the next protected swing in the same thesis.
- Re-enter only after later structure gives a cleaner invalidation distance.

## Structural Failure

- Cancel the setup when price turns into overlap and range instead of fast follow-through.
- Avoid new entries once the higher-timeframe target has already been reached.
- Drop the original thesis when price rotates back through the range and breaks the expected structure.
