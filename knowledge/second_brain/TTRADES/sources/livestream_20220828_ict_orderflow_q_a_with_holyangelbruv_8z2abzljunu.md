## Mistakes and warnings
- Skipping through timeframes without a higher-timeframe narrative and seeing valid setups both ways. Fix: Set the HTF narrative first; use the 15m/1h for POIs. (14:10)
- Trading random order blocks without a narrative. Fix: Use order blocks only in line with the side of the curve / bias, ideally to refine an FVG entry. (28:30)
- Chasing a big run after the move. Fix: Stand aside if already green; re-enter only on order blocks / breakers in the trend if at all. (19:30)
- [guest] Stacking too many concepts (order flow, ICT, structure) and freezing when they conflict. Fix: Narrow down the setups; order flow takes long screen time to master. (22:10)
- Judging a strategy by win rate. Fix: Look at win rate together with R:R and consistent position sizing. (55:00)
- [guest] Trusting resting limit orders on the ES DOM. Fix: Watch what trades at market; limit orders can be pulled. (44:00)
